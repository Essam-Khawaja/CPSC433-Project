\section{Shared Model: OR-Tree Validity Search}
\label{sec:or}

OR-tree search fits the first stage because any complete
valid timetable is an acceptable starting point for
optimization. Each branch represents a sequence of slot
assignments, and the search stops after finding one valid
completion. This stage does not minimize soft penalties.

\subsection{Search model}
\label{sec:or-model}

The model is $A_{\lor}=(S_{\lor},T_{\lor})$.

\paragraph{Problem descriptions.}
A problem description records the current partial assignment
and the components still to schedule:
\[
\mathit{Prob}_{\lor}
=\{(\mathit{assign},U):
  \mathit{assign}\text{ is a partial assignment},\
  U=X\setminus\operatorname{dom}(\mathit{assign})\}.
\]

\paragraph{States.}
A search state is an OR-tree, so
$S_{\lor}\subseteq\mathit{Otree}$.
A leaf is $(pr,sol)$, where
$pr\in\mathit{Prob}_{\lor}$ and
$sol\in\{\mathsf{yes},?,\mathsf{no}\}$.
An internal node is $(pr,sol,b_1,\ldots,b_r)$,
where each $b_i$ is an OR-tree.

\paragraph{Alternatives.}
For an unassigned component $x$, its currently legal slots are
\[
D_{\mathit{assign}}(x)
=\{s\in D(x):
  \mathrm{Consistent}(
    \mathit{assign}\cup\{x\mapsto s\})\}.
\]
For a consistent partial assignment, select $x\in U$ and
write $D_{\mathit{assign}}(x)=\{s_1,\ldots,s_r\}$.
When $r>0$, define
\[
\mathit{Altern}(pr,pr_1,\ldots,pr_r),
\]
where
\[
pr=(\mathit{assign},U),
\qquad
pr_i=
(\mathit{assign}\cup\{x\mapsto s_i\},U\setminus\{x\}).
\]
Each child assigns the same component to a different legal
slot. Together, the children cover every valid completion
of the parent.

\paragraph{Extension rules and transitions.}
We use the following $\mathit{Erw}_{\lor}$ operations:
\begin{enumerate}
  \item Mark a leaf $(pr,?)$ as $(pr,\mathsf{yes})$ when
  $U=\varnothing$ and
  $\mathrm{Constr}(\mathit{assign})=\mathsf{true}$.

  \item Mark a leaf $(pr,?)$ as $(pr,\mathsf{no})$ when
  $\mathrm{Consistent}(\mathit{assign})$ is false, or
  some $x\in U$ has
  $D_{\mathit{assign}}(x)=\varnothing$.

  \item Expand an unresolved leaf using its alternatives:
  \[
  (pr,?)
  \longrightarrow
  (pr,?,(pr_1,?),\ldots,(pr_r,?)).
  \]

  \item Apply an operation within a subtree:
  \[
  (pr,?,b_1,\ldots,b_i,\ldots,b_r)
  \longrightarrow
  (pr,?,b_1,\ldots,b_i',\ldots,b_r)
  \]
  whenever $\mathit{Erw}_{\lor}(b_i,b_i')$ holds.
  All other subtrees remain unchanged.
\end{enumerate}
These operations define the transitions used by our process:
\[
T_{\lor}
=\{(q,q')\in S_{\lor}\times S_{\lor}:
  \mathit{Erw}_{\lor}(q,q')\}.
\]
Failed alternatives remain marked $\mathsf{no}$ while the
control explores other unresolved leaves.

\subsection{Search process}
\label{sec:or-process}

The process is
$P_{\lor}=(A_{\lor},\mathit{Env}_{\lor},K_{\lor})$.
The environment contains the scheduling instance and fixed
orders for components and slots.

The control selects the deepest unresolved leaf (depth-first search), breaking
ties by selecting in the order in which children were generated. It
first checks whether the leaf can be marked
$\mathsf{yes}$ or $\mathsf{no}$. Otherwise, it selects an
unassigned component using minimum remaining values (MRV):
\[
x^*\in\operatorname*{arg\,min}_{x\in U}
|D_{\mathit{assign}}(x)|.
\]
Ties are resolved by the fixed component order. The selected
leaf is expanded with all legal slots for $x^*$, listed
in the fixed slot order.

This schedules the most restricted remaining component
first. Depth-first exploration follows one assignment
sequence until it succeeds or fails, then selects another
unresolved leaf.

\subsection{Search instance and stopping condition}
\label{sec:or-instance}

The search instance is
$\mathit{Inst}_{\lor}=(q_0,G_{\lor})$, with
\[
q_0=((\varnothing,X),?).
\]
Mandatory assignments are enforced through the domains and
the consistency checker defined in Section~\ref{sec:problem}.

Let $\mathit{Leaves}(q)$ denote the leaves of tree $q$.
The stopping condition is
\[
\begin{aligned}
G_{\lor}(q)=\mathsf{yes}\iff{}&
\exists(pr,\mathsf{yes})\in\mathit{Leaves}(q)\\
&{}\lor
\forall(pr,sol)\in\mathit{Leaves}(q):
sol=\mathsf{no}.
\end{aligned}
\]
In the first case, return the complete assignment in the
successful leaf. In the second, return FAILURE.

Without an early stop at the time limit, the search terminates
because every expansion assigns one additional component and
the domains are finite. Since every legal alternative is
included, it finds a valid timetable whenever one exists.
Its worst-case search size is exponential.

\subsection{Worked OR-tree derivation}
\label{sec:or-example}

Let $X=\{x,y,z\}$ be three lectures of different,
non-500-level courses. Each has domain $\{s_1,s_2\}$,
where $s_1$ is MWF 9:00--10:00 and $s_2$ is
MWF 10:00--11:00. Both slots have lecture capacity two.
The only conflict is $\mathit{notcompatible}(x,y)$.
There are no preassignments, active-learning requirements,
or other restrictions affecting these lectures.

Use component order $x<y<z$ and slot order $s_2,s_1$.
Initially,
\[
pr_0=(\varnothing,\{x,y,z\}),
\qquad q_0=(pr_0,?).
\]
All domains have size two, so the control selects $x$.
The rule
\[
\mathit{Altern}(pr_0,pr_1,pr_2)
\]
uses
\[
pr_1=(\{x\mapsto s_2\},\{y,z\}),
\qquad
pr_2=(\{x\mapsto s_1\},\{y,z\}).
\]
Applying the expansion gives
\[
q_0\longrightarrow
q_1=(pr_0,?,(pr_1,?),(pr_2,?)).
\]

The control selects $(pr_1,?)$. Here $y$ has only $s_1$
available because it cannot overlap $x$, whereas $z$
still has two choices. Thus MRV selects $y$, and
\[
\mathit{Altern}(pr_1,pr_3),
\qquad
pr_3=(\{x\mapsto s_2,y\mapsto s_1\},\{z\}).
\]
The recursive extension rule gives
\[
q_1\longrightarrow
q_2=(pr_0,?,(pr_1,?,(pr_3,?)),(pr_2,?)).
\]

At $pr_3$, both slots remain legal for $z$. Applying
$\mathit{Altern}(pr_3,pr_4,pr_5)$ creates two complete
assignments:
\[
\begin{aligned}
pr_4&=(\{x\mapsto s_2,y\mapsto s_1,z\mapsto s_2\},
       \varnothing),\\
pr_5&=(\{x\mapsto s_2,y\mapsto s_1,z\mapsto s_1\},
       \varnothing).
\end{aligned}
\]
The control selects $(pr_4,?)$ first and marks it
$(pr_4,\mathsf{yes})$, since all hard constraints hold.
The search returns
\[
\mathit{assign}_0
=\{x\mapsto s_2,y\mapsto s_1,z\mapsto s_2\}.
\]
The leaves for $pr_2$ and $pr_5$ remain unexplored as one successful leaf is sufficient.
