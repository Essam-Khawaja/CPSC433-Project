\section{Proposal A: Set-Based Improvement Search}
\label{sec:set}

Set-based search represents a complete timetable as a set
of assignment facts. This allows us to improve the timetable
by replacing individual assignments while keeping it valid.
We use greedy hill climbing: at each iteration, choose a
valid change with the lowest resulting penalty and apply
it only if it improves the current timetable. This approach
can stop at a local optimum.

\subsection{Search model}
\label{sec:set-model}

The model is $A_{\mathrm{set}}=(S_{\mathrm{set}},
T_{\mathrm{set}})$.

\paragraph{Facts and states.}
Each fact records the slot assigned to one component:
\[
F=\{\mathrm{Assigned}(x,s):x\in X,\ s\in D(x)\}.
\]
For a set $q$ containing exactly one assignment fact for
each component, let $\mathit{assign}_q$ be the timetable
defined by
\[
\mathit{assign}_q(x)=s
\iff \mathrm{Assigned}(x,s)\in q.
\]

Our states represent complete valid timetables:
\[
S_{\mathrm{set}}
=\{q\subseteq F:
  q\text{ assigns every }x\in X\text{ exactly once},
  \ \mathrm{Constr}(\mathit{assign}_q)=\mathsf{true}\}.
\]

\paragraph{Extension rules.}
We define two types of rule in
$\mathit{Ext}\subseteq\{A\to B:A,B\subseteq F\}$.

A \textbf{Move} changes one component's slot:
\[
\{\mathrm{Assigned}(x,s_1)\}
\longrightarrow
\{\mathrm{Assigned}(x,s_2)\},
\qquad s_1\neq s_2.
\]

A \textbf{Swap} exchanges the slots of two distinct
components:
\[
\begin{aligned}
\{&\mathrm{Assigned}(x,s_1),
   \mathrm{Assigned}(y,s_2)\}\\
&\longrightarrow
\{\mathrm{Assigned}(x,s_2),
  \mathrm{Assigned}(y,s_1)\},
\end{aligned}
\]
where $x\neq y$ and $s_1\neq s_2$.
All facts on both sides must belong to $F$.

A swap can allow an improvement when moving either
component alone would violate a hard constraint.
Both rules are applied only when the resulting timetable
remains valid, including its mandatory assignments.

\paragraph{Transitions.}
Applying $A\to B$ removes the facts in $A$ and inserts
the facts in $B$:
\[
q'=(q\setminus A)\cup B.
\]
The transition relation is
\[
\begin{aligned}
T_{\mathrm{set}}=\{(q,q')\in
S_{\mathrm{set}}\times S_{\mathrm{set}}:\ &
\exists A\to B\in\mathit{Ext},\\
&A\subseteq q,\quad
q'=(q\setminus A)\cup B\}.
\end{aligned}
\]
The state restriction ensures that every permitted
transition keeps the timetable valid. Whether the
transition improves its penalty is decided by the control.

\subsection{Search process}
\label{sec:set-process}

The process is
$P_{\mathrm{set}}=(A_{\mathrm{set}},
\mathit{Env}_{\mathrm{set}},K_{\mathrm{set}})$.
The environment contains the scheduling instance, the
current fact set $q$, and a fixed ordering of extension
rules for breaking ties.

\paragraph{Applicable extensions.}
The currently applicable rules are represented by
\[
R(q)=\{(A,B):
 A\to B\in\mathit{Ext},\
 A\subseteq q,\
 (q\setminus A)\cup B\in S_{\mathrm{set}}\}.
\]

\paragraph{Weight function.}
Let $q(e)$ be the current fact set recorded in environment
$e$. We score each applicable rule by the total penalty
after applying it:
\[
f_{\mathrm{wert}}(A,B,e)
=\mathrm{Eval}\!\left(
 \mathit{assign}_{(q(e)\setminus A)\cup B}
 \right).
\]

\paragraph{Selecting and applying an extension.}
When $R(q)\neq\varnothing$, let
\[
R_{\min}(q,e)
=\operatorname*{arg\,min}_{(A,B)\in R(q)}
 f_{\mathrm{wert}}(A,B,e).
\]
The selection function chooses the first rule in the
fixed ordering among these equally best rules:
\[
(A^*,B^*)=f_{\mathrm{select}}(R_{\min}(q,e),e).
\]
Set $q'=(q\setminus A^*)\cup B^*$.
The control applies this transition only when
\[
\mathrm{Eval}(\mathit{assign}_{q'})
<
\mathrm{Eval}(\mathit{assign}_q).
\]
In that case, $K_{\mathrm{set}}(q,e)=q'$.
Otherwise, the stopping condition below holds and no
further transition is taken.

\subsection{Search instance and stopping condition}
\label{sec:set-instance}

The instance is
$\mathit{Inst}_{\mathrm{set}}=(q_0,G_{\mathrm{set}})$.
Using the valid timetable returned by OR-tree search,
\[
q_0=
\{\mathrm{Assigned}(x,\mathit{assign}_0(x)):x\in X\}.
\]

Define the neighboring states by
\[
N(q)=\{q'\in S_{\mathrm{set}}:(q,q')\in T_{\mathrm{set}}\}.
\]
The search stops at zero penalty or when no valid Move
or Swap improves the timetable:
\[
\begin{aligned}
G_{\mathrm{set}}(q)=\mathsf{yes}\iff{}&
\mathrm{Eval}(\mathit{assign}_q)=0\\
&{}\lor
\neg\exists q'\in N(q):
\mathrm{Eval}(\mathit{assign}_{q'})
<
\mathrm{Eval}(\mathit{assign}_q).
\end{aligned}
\]

Each accepted transition strictly reduces the penalty.
Since there are finitely many complete assignments, the
process terminates if allowed to finish. Its result is a
local optimum: no valid Move or Swap improves it, although
another timetable may have a lower penalty.

\subsection{Worked set-based derivation}
\label{sec:set-example}

Consider three lectures $x,y,z$ of different, non-500-level
courses and two slots: $s_1=$ MWF 9:00--10:00 and
$s_2=$ MWF 10:00--11:00. Each lecture may use either slot,
each slot has capacity two and minimum zero, and $x$ and
$y$ must not overlap. There are no other hard restrictions
affecting these lectures.

The only nonzero preferences are
\[
\mathit{preference}(x,s_1)=4,\qquad
\mathit{preference}(y,s_1)=2,\qquad
\mathit{preference}(z,s_1)=1.
\]
All other soft-constraint contributions are zero.
Suppose OR-tree search returns
\[
\mathit{assign}_0
=\{x\mapsto s_2,y\mapsto s_1,z\mapsto s_2\}.
\]

\paragraph{First iteration.}
Moving $z$ to $s_1$ would give penalty 4.
Moving $x$ or $y$ alone would make them overlap,
violating their incompatibility.

Swapping $x$ and $y$ gives penalty 3 and is the best
valid change. The selected rule has
\[
\begin{aligned}
A&=\{\mathrm{Assigned}(x,s_2),
     \mathrm{Assigned}(y,s_1)\},\\
B&=\{\mathrm{Assigned}(x,s_1),
     \mathrm{Assigned}(y,s_2)\}.
\end{aligned}
\]
Applying $A\to B$ gives
\[
\begin{aligned}
q_1=(q_0\setminus A)\cup B
=\{&\mathrm{Assigned}(x,s_1),
    \mathrm{Assigned}(y,s_2),\\
   &\mathrm{Assigned}(z,s_2)\}.
\end{aligned}
\]
The new timetable satisfies every hard constraint and
has penalty $3<5$, so the control accepts it.

\paragraph{Second iteration.}
The control selects the Move rule
\[
\{\mathrm{Assigned}(z,s_2)\}
\longrightarrow
\{\mathrm{Assigned}(z,s_1)\}.
\]
The resulting state is
\[
q_2=
\{\mathrm{Assigned}(x,s_1),
  \mathrm{Assigned}(y,s_2),
  \mathrm{Assigned}(z,s_1)\},
\qquad
\mathrm{Eval}(\mathit{assign}_{q_2})=2.
\]
Slot $s_1$ contains two lectures, within its capacity,
and $x$ and $y$ remain separated.

No valid Move or Swap reduces the penalty further,
so $G_{\mathrm{set}}(q_2)=\mathsf{yes}$.
The process returns
$\mathit{assign}_A=\mathit{assign}_{q_2}$.
