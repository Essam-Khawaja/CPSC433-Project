\begin{abstract}
We consider the CPSC 433 course timetabling problem: assigning lectures and tutorials to weekly slots while satisfying hard constraints and minimizing penalties for soft constraints. We propose two alternative search systems that share an OR-tree feasibility stage. The OR-tree represents partial assignments as problem descriptions and applies depth-first search with minimum remaining values to find an initial valid timetable. In Proposal A, set-based search represents the timetable as assignment facts and applies valid Move and Swap extensions using greedy hill climbing. In Proposal B, AND-tree search divides the optimization problem into assignment cases and uses branch-and-bound with the feasible timetable as an initial incumbent. Both alternatives preserve hard constraints and can improve the initial evaluation score. The set-based process is simpler but can stop at a local optimum; the AND-tree process can establish global optimality if exhaustive exploration and sound pruning complete. We specify the models, controls, stopping conditions, and worked examples using the terminology of the project problem description and course lectures.
\end{abstract}
