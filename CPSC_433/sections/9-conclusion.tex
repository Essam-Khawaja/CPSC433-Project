\section{Conclusion}
We proposed two complete timetabling pipelines sharing an OR-tree feasibility stage. The set-based branch offers simple, feasibility-preserving local improvement, whereas AND-tree branch-and-bound searches across alternative assignments and can prove an optimum when completed. Both use the same hard-constraint checker and evaluation objective. The proposed models and worked derivations specify how each search process can be instantiated for the course timetabling problem.
