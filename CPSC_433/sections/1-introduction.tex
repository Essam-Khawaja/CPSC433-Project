\section{Introduction}
\label{sec:intro}
The objective is to assign lectures and tutorials to permitted weekly slots so that every hard constraint holds and the soft-constraint penalty is minimized. This proposal compares two ways to improve a valid timetable: OR-tree feasibility followed by set-based local search, or OR-tree feasibility followed by AND-tree branch-and-bound. Section~\ref{sec:problem} formalizes the scheduling instance once; later sections instantiate the search models and controls without redefining the same constraints.
