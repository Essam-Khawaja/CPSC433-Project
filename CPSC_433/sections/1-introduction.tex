We are aiming to solve the problem of creating academic schedules for a semester at the University of Calgary, by making a single weekly schedule (which is then repeated for 13 weeks) containing $\mathit{Lectures}$ and $\mathit{Tutorials}$ sections (belonging to a course) which fit in weekly room time $\mathit{Slots}$ with designated start and end times. There can be multiple $\mathit{Tutorials}$ sections which subdivide a particular $\mathit{Lectures}$ section and there can be more than one $\mathit{Lectures}$ section. Furthermore, there are a number of specified hard and soft constraints on how each lecture/tutorial can fit into the available room time $\mathit{Slots}$ (from Monday-Friday). There are two categories of room time $\mathit{Slots}$, one for lectures and the other for tutorials, along with specific ``active learning'' designation for some rooms, with the number of rooms limited per slot. This problem is similar to what a student would do when creating a weekly class schedule in Schedule Builder, although we are creating the section times which students pick from.

The objective is to assign lectures and tutorials to permitted weekly slots so that every hard constraint holds and the soft-constraint penalty is minimized. This proposal compares two ways to improve a valid timetable: OR-tree feasibility followed by set-based local search, or OR-tree feasibility followed by AND-tree branch-and-bound. Section~\ref{sec:problem} formalizes the scheduling instance once; later sections instantiate the search models and controls without redefining the same constraints.



\subsection{Models proposed}
We consider three search paradigms:
\begin{itemize}
  \item \textbf{OR-tree}: find one feasible timetable.
  \item \textbf{Set-based}: improve a feasible timetable through local changes.
  \item \textbf{AND-tree}: systematically explore scheduling decisions to seek a globally optimal timetable, using branch-and-bound.
\end{itemize}
